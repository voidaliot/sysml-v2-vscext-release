BEFORE YOU START

A few practical details.

The tools, the files, and what stays local. Find the full setup and feature guidance in the documentation.

Read the user guide
Do I need Java or a diagram server?

No separate Java runtime or PlantUML server is required for the extension’s modeling workflow. The extension includes its language service and the standard library.

Where are my models and layouts stored?

The model stays in your .sysml or .kerml files. Diagram presentation is stored separately under .vscode/sysml/diagrams/. You decide which files to commit to Git.

Does it work in browser-hosted VS Code?

The documented web support includes language services and editable diagrams. Features that require local filesystem or Node.js access, including the companion CLIs and archive workflows, have desktop-specific requirements. Check the user guide for the current compatibility details.

Is an AI account required?

No. The modeling workflow does not require an AI model or AI account. Agent tools are optional. A separately enabled agent or service may transmit the context you choose to share under that service’s own policies.

Which themes are included?

Choose Aliot Light or Aliot Dark in VS Code. Diagrams follow your active editor theme. This page has its own light and dark switch.

What is the current license?

Aliot is available under its Freeware License. Bundled libraries retain their upstream licenses. Read the license for the terms.
