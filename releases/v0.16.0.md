### Added

- **Keep a block exactly as you wrote it.** Put `// sysml-format ignore` above an element and the formatter leaves its layout alone.
- **Formatter style is now a project setting.** `sysml.format.*` sets indentation, blank lines, line width, empty bodies, quotes, and keyword spelling. Defaults keep today's output.
- **Hover shows documentation an element inherits**, from its definition or the nearest type it specializes, with the source named and linked.
- **Inlay hints for what the model says but the text does not**: implicit `private`, implicit `ref`, library specializations, parameter redefinitions, effective names.
- **Two of those hints write themselves.** Double-click the `private` or `ref` hint and the modifier is inserted.

### Fixed

- **A comment no longer un-indents the block it sits in.** A body whose first line was a comment was pulled back to column 0.
- **Formatting no longer adds blank lines at the top of a file.** A file starting with `package` gained two of them every time.
