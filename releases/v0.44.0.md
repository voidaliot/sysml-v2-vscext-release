### Added

- A metadata annotation written with `about` now links to every element it names, across package boundaries. A target the diagram cannot show is named on the card instead.

### Fixed

- A keywordless tagged member (`#subsystem engine;`) now shows the same composite membership as the written part beside it. An untagged bare member is unchanged, and so is a bare member tagged in its body or through `about`: it stays a reference usage.
- A definition tagged through a usage base type (`action def Save { @Command; }`) now specializes the definition of that usage, as OMG 7.27.3 states. It gained no relationship before.
- A user-defined keyword (`#subsystem`) is now highlighted like the `@Tag` it stands for, in SysML files and in both bundled themes.
- A bare member of a part (`trimLevel;`, `mass : MassValue;`) now lists in the `features` compartment. It was listed under `enums`, or dropped when typed, and a tagged bare part was listed twice.
- Checks that apply to a composite part now apply to a tagged one too, so a tagged member valued by a data type is reported like the written part is.
- A note whose `about` target sits outside the diagram is no longer attached to an enclosing package. It names the target instead.
