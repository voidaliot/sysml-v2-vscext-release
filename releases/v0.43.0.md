### Added

- User-defined keywords work. A `#tag` whose metadata definition specializes `SemanticMetadata` now gives the element it tags the base type that definition names.
- A keywordless tagged declaration (`#subsystem engine;`) gains the kind its keyword stands for, and its hover card names the kind and the relationship the tag adds.
- Names resolve through the new relationship, so `engine.powerRating` finds the attribute the base type declares.
- An import or package `filter` matches a keywordless tagged declaration by the kind its keyword gives it.
- The SysML v2 JSON export writes the relationship a keyword adds, marked as implied.
- Diagrams draw the relationship a keyword adds. The General View shows it as the relationship it stands for, with the keyword in guillemets so it reads apart from a written one.
- A keywordless tagged declaration (`#subsystem engine;`) now carries the banner its keyword gives it, sorts with that kind, and appears in the Interconnection View as the part it is.
- Six checks report a base type that is missing, unreadable, not a type, stated twice in one body, applied to something that is not a type, or pointing back at the element it starts from.

### Fixed

- A metadata annotation is no longer asked to bind the occurrence features (`timeSlices`, `snapshots` and the rest) that its definition inherits from the metaclass root.
