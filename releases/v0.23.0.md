### Added

- **Connection notation is complete.** Definition links, end labels, adornments, and compartments stay visible.
- **Explicit connections are low-profile blocks.** Named end dots bind or reconnect to ports. New blocks start with two ends.
- **Connection blocks can use compact notation.** Complete binaries become lines, n-ary usages become buses, and partial binaries stay blocks.
- **Compact connection lines show names.** Named connections keep their identity when their block is hidden.
- **IV and STV definitions hide independently.** Definitions and their `«defined by»` links have separate remembered controls.
- **Anonymous n-ary connections form clean buses.** Lines meet the hub circle, and orthogonal spokes share trunks.
- **Explicit interfaces are blocks.** Low-profile blocks use named port-end dots. A separate filter shows labelled compact lines or hubs.

### Fixed

- **Connection hubs match end dots.** Anonymous n-ary hubs use the same size and outline colour as explicit connection end dots.
- **Geometry View rotates solids.** Resolved coordinate frames turn wheels and other shapes without false approximation warnings.
- **Geometry overviews show placed layouts only.** Unplaced shape inventories no longer create empty tiles. Labels are concise and axes stay visible.
- **OMG spatial models stay focused.** Interconnection View omits inherited library collection backbones instead of expanding them as parts.
- **Relationship documentation stays inside its block.** Connection and interface docs keep their block in compact mode.
- **Connected inherited usages stay visible.** Unconnected inherited ones stay hidden. Bindings survive specialization and redefinition.
- **Closed parts hide their internals.** Internal connections no longer return as port-like proxies.
- **Closed parts resize again.** Open and closed forms remember independent sizes.
- **Connection end actions stay focused.** End dots edit bindings only, and reverse drags keep the selected port face.
- **Connection definition notation stays complete.** Bundled lines retain labels, adornments, and elaboration links.
- **General View connection filters are reliable.** Binary and n-ary definitions remain visible and filter together.
- **Diagram search covers visible IV definitions.** Definition frames and ports now participate in Browser View filtering.
- **Interface end blocks bind only to ports.** Partial and unresolved ends remain visible for editing.
