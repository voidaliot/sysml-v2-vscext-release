### Added

- **Diagram placement has Undo and Redo.** Move, resize, port, routing, and docking changes can be reversed per view without relayout.
- **Action Flow performers use reliable resizable lanes.** Shared actions appear once in a combined performer lane; adding/removing a performer edits its exact claim.
- **Light color theme.** `SysML v2 Gray` keeps a Light Modern-like syntax palette on gray editor and workbench surfaces.
- **Action Flow editing covers the full action vocabulary.** Create structured branches/loops, marked succession flows, explicit send/accept, and targeted terminate.
- **Performer overlays now follow `perform`.** Dashed regions select independently and remove only their represented claims without deleting actions.
- **Anonymous action calls become addressable only when needed.** Drawing an edge atomically promotes that local `perform` to a unique named `references` occurrence.

### Changed

- **Modeled diagram text stays complete.** Documentation, comments, and representations are no longer shortened before compartments and Properties.
- **Reset Connector Routing now resets snap points too.** It saves new automatic paths and docks while keeping every node, frame, and port in place.
- **Action Flow definitions and typing links hide separately.** Two remembered controls preserve all placement when either layer is hidden and shown again.
- **Fork and join bars turn from their context menu.** Their thickness stays fixed, only their length resizes, and the saved orientation restores exactly.
- **Action Flow transitions are dotted.** Control successions no longer look like continuous item-transfer lines.
- **Action Flow creation stays flow-focused.** Action menus omit attributes and undirected items; directed items remain available as pins.
- **Action Flow menus omit empty swimlane creation.** Use Add performer to assign an existing part; performer lanes remain fully supported.
- **Performer edits keep the diagram stable.** Positions stay fixed, shared actions use normal styling, and the affected lane highlights subtly.
- **Terminate is now a relationship from an existing action.** It writes inline for empty actions and `then terminate;` after action bodies.
- **Element colors use explicit theme-aware surfaces.** Every role has independently tunable light/dark outlines and fills, without tint mixing.
- **Semantic diagram colors stay centralized.** Compartment rules follow their element; connections, transitions, and other lines have light/dark roles.
- **Structured actions match action notation.** Named controls are solid, open `«action»` frames with pins; inline controls and bottom `«until»` conditions use editable one-line clauses.
- **Structured flow follows the model.** Branch frames add no phantom arrows, loops accept multiple actions, and outer successions connect to loop frames.
- **Actions can be owned by use cases.** Reparenting changes action ownership without conflating it with performer claims.
- **Performer editing stays on the diagram.** Filter valid parts in place; Properties lists every claim, and outward drag removes the exact selected `perform`.
- **Compartment text has clearer breathing room.** Title and row descenders no longer crowd the following delimiter.
- **Behavior boundaries distinguish ownership, performance, and exhibition.** Ownership stays solid; exhibitors wrap the exact state, and package STV creates states rather than part tiles.
- **Action endpoints keep their roles.** Pins connect to pins; structural ports are accepted only by explicit send/accept endpoints.
- **Action Flow editing follows what you point at.** Creation nests in the deepest frame, overlay drops retarget claims, and parent bodies no longer steal highlights.
- **Flow chrome reflects the model.** Start/done appear only when connected; accept inputs dock on top, and loop `until` is a bottom editable field.
- **Terminate notation keeps names off the glyph.** A named terminate action appears before the standard unlabeled circled X.
- **Ownership and performance hide independently.** AFV has separate controls for solid owner-part boundaries and dashed performer overlays.
- **Branch controls fan out cleanly.** Diamonds and fork/join bars expose perimeter snap points; guards clear their decision.

### Fixed

- **Behavior pseudostates select reliably.** AFV/STV start and done keep a clickable center while connector dots remain on the circle.
- **Package overview frames resize in every canvas view.** IV, AFV, STV, Sequence, and Geometry persist package frame sizes like GV.
- **General View re-layout keeps Group sections.** Compartments survive reset, and switching through Tree restores the separate Group placement.
- **Every connector style restores exactly.** Straight, curved, and orthogonal paths, labels, and snap points round-trip through JSON.
- **Saved views reopen without layout.** IV, AFV, STV, and CV restore their JSON placement before automatic layout can run.
- **Zoom saves through view changes.** The final zoom and direction are flushed before a diagram closes or retargets.
- **Package headers stay inside their tab.** Long package names and library banners end in an ellipsis before the folder slope.
- **Small elements keep text inside.** Titles, lists, and conditions end in an ellipsis with complete hover text.
- **General View modes keep separate placements.** Group and Tree restore their own nodes, routes, snap points, direction, and zoom.
- **General View compartment titles stay visible.** Returning from Tree restores Group card heights and titled feature lists.
- **Action and State ranks use middle spacing.** Transition labels no longer create empty ranks, and old saved behavior geometry refreshes once.
- **Behavior snap points meet circular controls.** Start, done, and terminate connectors dock on the glyph, including after restore.
- **Part-owned Action Flow package views stay clear.** Nested actions and send/accept shapes no longer stack when overview tiles lay out.
- **Automatic connectors spread cleanly.** Snap points follow endpoint order, and routing avoids hiding one line under another.
- **Ordinary diagram edits keep existing geometry.** Stable elements and routes stay put. Only new elements receive local placement.
- **All diagram placement now round-trips.** Node, frame, port, route, snap point, and zoom data is saved. Pan and scroll stay transient.
- **Diagram chrome stays compact.** Title controls appear on hover or selection, labels keep model case without masks, and GV cards stop at 320 px.
- **State-machine starts stay warning-free.** `STYL009` now checks only adjacent Action Flow steps and keeps start/done local to their behavior.
- **Parallel regions stay concurrent.** STV refuses transitions between direct child regions, and textual notation reports `SSM028`; transitions inside each region remain valid.
- **Action Flow terminals stay source-backed.** Plain successions no longer invent start/done, and then-done writes inside the owning behavior.
- **Exhibited state boundaries stay put.** Moving states inside them can grow the boundary without dragging its top-left position.
- **Collapsed containers match General View cards.** Hidden internals leave no blank body or duplicate bottom separator, including around ports and pins.
- **Action feature compartments are restored.** Docs, attributes, and plain items show on leaf/composite actions, while Properties includes all internals.
- **Performer assignment finds local actions in typed usages.** Actions such as `captureAndStore.store` can now be assigned to an existing part.
- **Structured controls can be completed on the canvas.** Create any control inside actions; add missing else/while/until clauses or promote it with a name.
- **Diagram-created behavior paths use the right separator.** Definition members use `::`; usage members continue to use `.` in `perform` and `exhibit` references.
- **AFV performer choices exclude reference aliases.** The in-diagram picker now lists only concrete non-`ref` part usages eligible to claim an action.
- **Action containers avoid duplicate members.** Owned/performed actions appear as internals, not again in an `actions` list.
- **Behavior lanes use compact headers.** Performer separators are gone; exhibited-by lanes list parts and remove claims individually.
- **Container cards stay solid and snug.** Open frames keep solid title/list bands, padded children, and no saved-height strip when collapsed.
- **Performer lanes stay inside their action owner.** Reused performers get local lanes; combined names share one comma-separated line.
- **Loop creation and succession authoring now preserve valid SysML.** Right-click accepts named/inline controls; anonymous targets move below the source with lexical `then`.
- **Toolbar selections stay readable across themes.** Pressed icons now use the active theme's matching control foreground and background colors.
