### Added

- The diagram toolbar has a Save button beside Redo. It saves the model file and its diagram JSON with the normal VS Code save, and it lights up only when something is unsaved.

### Changed

- The diagram now has one presentation: a full editor tab. Use the VS Code split editor to place it beside the model. The dock and expand buttons, Ctrl+Alt+D, and the defaultMode setting are gone.
- A narrow diagram tab keeps its canvas usable. The Browser View and Properties panels fall back to their rails and return with the width.

### Fixed

- The diagram JSON no longer opens a tab in front of the diagram. It gets a tab only while it holds unsaved layout, which is what File > Save All needs, and it opens in the background so the first move no longer makes the diagram flicker.
